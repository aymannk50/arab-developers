# ArabDev

A community-driven directory for discovering Arab developers, designers, and technology professionals across the MENA region.

## Live Website

[Visit ArabDev](https://arab-developers-orpin.vercel.app/)

## Features

- Search developers by name or skill
- Filter developers by country
- Filter developers by specialty
- Visit developer portfolios
- Add new profiles through GitHub
- Responsive on computers and mobile devices

## Join the Directory

Are you an Arab developer, designer, or technology professional?

Read the [Contribution Guidelines](CONTRIBUTING.md) to add your profile.

## How to Contribute

1. Fork this repository.
2. Create a new branch.
3. Add your profile to `data/developers.json`.
4. Commit and push your changes.
5. Open a Pull Request.
